# Лабораторна робота №9: Класифікація зображень за допомогою CNN

* **Виконавець:** Адамчук Ярослав
* **Варіант:** `n = 2`
* **Обрані класи Food-101:**
  * `0` (індекс `1`): `baby_back_ribs`
  * `1` (індекс `31`): `donuts`
  * `2` (індекс `61`): `lobster_roll_sandwich`
* **Джерело даних:** [Food-101 Dataset (ETH Zurich)](https://data.vision.ee.ethz.ch/cvl/datasets_extra/food-101/)

## Структура папки `Lab9`
* `lab9_cnn.ipynb` — повний код експериментів, ручний розрахунок згортки, навчання моделей, візуалізація кривих навчання, матриці помилок та карт ознак.
* `manifest.json` — фіксація поділу вибірки (`train`: 1800, `val`: 450, `test`: 750) з `seed=42` та перевіркою цілісності за SHA-256.
* `class_names.json` — список класів у порядку вихідних нейронів моделі.
* `results/` — порівняльна таблиця експериментів на валідації (`validation_experiments.csv`) та підсумкові візуалізації.
